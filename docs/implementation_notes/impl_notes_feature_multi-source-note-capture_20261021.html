持久化來源與佇列分開

決定
SQLite 記錄來源、成果、校對及刪除狀態，私人 volume 存必要暫存；Celery 只傳來源／事件 ID；必要的 BYOK context 與待處理 LINE 事件在私人 DB 加密。
原因
Redis 結果不是永久來源紀錄；重試、去重及清理需要共用可靠狀態。
影響
本版限定同機 web／worker 共享本機 volume；多主機需更換管理資料庫與暫存。
驗證
暫存資料庫測試重送、重試與刪除後不再建回。
狀態
已實作；A–F 獨立審查通過。

精簡保存與目的地隔離

決定
Drive 文字兩檔、語音三檔；圖片／PDF 僅原檔。Notion 只保存完整文字與摘要；BYOK 限自己的 Notion。
原因
支援原文回查與獨立清理，不累積每階段永久副本。
影響
OCR、附件摘要、Notion 附件、Atlas 索引及歷史遷移不在本版。
驗證
離線替身驗證檔案集合、來源完整性與隔離。
狀態
使用者已確認。

LINE 管理與垃圾桶

決定
指令與按鈕共用清理服務；人工校對後手動清原檔，指定檔案／整筆可明確移除唯一內容；只移至垃圾桶。
原因
LINE 作為日常入口，預覽明確清單避免範圍歧義。
影響
需要身分綁定、限時清單與去重；刪除必須阻止舊任務再建回。
驗證
偽造身分、過期／重放、跨來源刪除與工作競態測試。
狀態
使用者已確認。

外部審查流程的適用範圍

決定
參考指定 commit／code-review 技能通用流程；以個人部署及允許的雲端寫入為威脅模型。

驗證

狀態
已執行外部腳本；初始文件無 secret 或禁止檔案。

可重現部署與依賴修補

決定
追蹤 lock，升級 FastAPI／Starlette、cryptography 及 multipart；移除未用 LINE SDK，明列 Drive transport，加入選用 OAuth setup 與開發 Ruff。
原因
完整 runtime lock 掃描發現舊加密、Web 與 multipart 公告；避免容器重新解析到未驗證版本。OAuth 初始化工具解決 drive.file 根目錄初始授權。
影響
web／worker 分群安裝，SQLite volume 同機共用，Redis AOF 持久化；初始化只由操作者手動執行。格式整理讓全專案 lint 指令可直接驗證。
驗證
lock 匯出全部 runtime／worker／setup 供 pip-audit；離線測試、Compose schema 與映像建置。真實 OAuth、IAM、LINE 帳號與 HTTPS 不由離線驗證取代。
狀態
審查通過；未變更私人 .env 或部署真實帳號。

逐項驗收與隔離環境

決定
更新 TESTING_GUIDE，對照功能與自動測試，另列真實帳號驗收步驟、通過條件及證據；提供獨立 UAT Compose。

102 項離線測試與 Ruff、60 項驗收清單、Compose schema／隔離設定、文件連結；review_stage_f 已獨立複審操作與現行實作。真實 UAT 結果需由操作者另填。
狀態
審查通過；無剩餘必修或 High／Critical，未執行真實帳號驗收。
