持久化來源與佇列分開

決定
SQLite 記錄來源、成果、校對及刪除狀態，私人 volume 存必要暫存；Celery 只傳來源 ID 與必要的加密 context。
原因
Redis 結果不是永久來源紀錄；重試、去重及清理需要共用可靠狀態。
影響
本版限定同機 web／worker 共享本機 volume；多主機需更換管理資料庫與暫存。
驗證
暫存資料庫測試重送、重試與刪除後不再建回。
狀態
方案已確認，待實作。

精簡保存與目的地隔離

決定
Drive 文字兩檔、語音三檔；圖片／PDF 僅原檔。Notion 只保存完整文字與摘要；BYOK 限自己的 Notion。
原因
支援原文回查與獨立清理，不累積每階段永久副本。
影響
OCR、附件摘要、Notion 附件、Atlas 索引及歷史遷移不在本版。
驗證
離線替身驗證檔案集合、來源完整性與隔離。
狀態
使用者已確認。

LINE 管理與垃圾桶

決定
指令與按鈕共用清理服務；人工校對後手動清原檔，指定檔案／整筆可明確移除唯一內容；只移至垃圾桶。
原因
LINE 作為日常入口，預覽明確清單避免範圍歧義。
影響
需要身分綁定、限時清單與去重；刪除必須阻止舊任務再建回。
驗證
偽造身分、過期／重放、跨來源刪除與工作競態測試。
狀態
使用者已確認。

外部審查流程的適用範圍

決定
參考指定 commit／code-review 技能通用流程；以個人部署及允許的雲端寫入為威脅模型。
原因
Wayken 的多品牌、唯讀資料層、skills 鏡像等屬另一 repo 的規則。
影響
外部檢查腳本因本 repo 沒有 skills 鏡像報錯，此項記為不適用；lint、secret、位置及命名仍獨立檢查。
驗證
逐階段保存測試與審查結論；實帳號 IAM／OAuth 權限列為無法從 repo 驗證。
狀態
已執行外部腳本；初始文件無 secret 或禁止檔案。
